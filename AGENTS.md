## Default Behavior

- Work one deliverable at a time.
- Preserve the static architecture.
- Do not add dependencies unless explicitly requested.

- Keep the EN/ES toggle functional for all visible UI text.
- Update `README.md` when project behavior changes.
- Treat sources as reference material, not wholesale content injection.
- Mark missing sources as pending local source import.
- Preserve the Level 1 rule: nothing in the Idea Nebula is active or a task.
- Treat interactive selection as observation only; never imply activation.
