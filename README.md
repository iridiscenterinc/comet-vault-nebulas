Comet Vault Nebulas is a static HTML/CSS/vanilla JavaScript interactive
visualization proposal for a bilingual, source-aware creative vault. It rebuilds
the verified `v0.2.2` baseline as a Level 1 cognitive-relief surface: ideas can
be seen, named, and held without becoming tasks.

This directory is a separate candidate delta. The verified baseline attachment
was not edited.

## Purpose

The proposal demonstrates how Comet Vault can orient users through seven idea
clusters, three visual lenses, dual-system boundaries, candidate capsules,
governance previews, and a permanent provenance rail.

It is not a production backend, runtime, public release, skill installation,
repository merge, or canon.

## v0.3.0-rc1 Proposal Inventory

- Full-screen editorial hero with a dependency-free animated nebula canvas.
- Seven selectable Idea Nebula clusters derived from the inspected Level 1
  source.
- Three functioning lenses: Editorial Vault, Glassy Bokeh Lab, and Creative
  Archive.
- Dual-system boundary: internal candidate → D review → accepted public
  projection.
- Governance exit-path preview that performs no mutation.
- Candidate-module capsules with unmounted-state disclosure.
- Permanent provenance rail with source IDs, hashes, status, and D decision
  state.
- Responsive desktop/mobile layouts and reduced-motion support.
- EN/ES coverage for static and dynamic visible copy.

## Interaction Inventory

- EN/ES toggle updates visible translated copy and the document `lang`
  attribute.
- Cluster selectors update `aria-pressed` and the active bilingual cluster
  detail.
- Lens cards update `aria-pressed`, Current Lens, copy, and recommended next
  action.
- Exit-path buttons preview governance consequences without activating a task.
- Provenance rail supports open, close, backdrop, focus return, and Escape.
- Canvas animation responds subtly to pointer position and stops under
  reduced-motion preference.

## Visual Reference Boundary

`research-visualization.zip` was inspected as an aesthetic and interaction
reference only.

Reused as design principles:

- immersive full-screen scene;
- editorial serif hierarchy;
- scroll-led narrative sections;
- interactive explanatory diagrams;
- light/dark rhythm;
- restrained gold accent;
- orchestrated motion.

Excluded:

- AlphaQubit research text and data;
- React and TypeScript implementation;
- Three.js, React Three Fiber, Drei, Framer Motion, and Lucide;
- `.env.local` and API-key configuration;
- external runtime dependencies.

## Known Limits

- Static prototype only; no persistence, auth, routing, server, or backend.
- Browser code cannot inspect the local filesystem or validate source state.
- Public projection is modeled visually but remains locked and non-functional.
- GitHub publication remains `NOT_PUBLISHED`.
- RC1 package state and internal records remain unverified until mounted.
